🎯 Problem Statement

Colleges and organizations conduct multiple events such as workshops, seminars, competitions, hackathons, and project expos. Managing these events manually can lead to schedule clashes, venue conflicts, participant registration issues, overlapping events, and difficulty in tracking event information**.

Organizers often use separate spreadsheets, forms, and messages, making event coordination time-consuming and error-prone.

💡 Proposed Solution

Code Flux is an Event Management and Scheduling System** designed to simplify event planning and coordination. The system helps organizers create and manage events, handle participant registrations, avoid scheduling and venue conflicts, and keep all event-related information in one centralized platform.

AI-based features can assist in identifying possible conflicts and providing intelligent scheduling recommendations.

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript
Backend: Java
AI: Generative AI / Machine Learning
Database: MySQL
Version Control: Git & GitHub
